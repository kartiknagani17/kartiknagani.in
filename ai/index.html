Things I've built

Two projects where I wanted a real answer, so I measured everything.

Invoice extraction with a small fine-tuned model

Can a 3B open-source model read invoices almost as well as GPT-4o mini, for less money? I fine-tuned one with QLoRA on 800 examples I generated, cleaned and labelled myself. Then I tested both models on 100 invoices neither had seen.

  • 650 msmedian response time
  • 2x cheaperper 1,000 invoices than the API

It runs on vLLM on Modal's serverless GPUs, which scale to zero when nobody's using it. The weights are public on Hugging Face.

Python, Unsloth, Hugging Face TRL, QLoRA, Pydantic, vLLM, Modal

A test harness that catches RAG apps making things up

RAG apps invent answers, and you usually find out from a user. I built a document Q&A app and a harness that scores it on 100 questions with known answers. Did it find the right passage? Did it stick to it? Did it cite it properly?

  • 12experiments on chunking, hybrid search and reranking
  • 20% fewermade-up answers

It runs on AWS Lambda and deploys through GitHub Actions. Any pull request that makes the scores drop gets blocked, and a CloudWatch dashboard tracks latency and cost per query.

Python, FastAPI, Ragas, promptfoo, Qdrant, Docker, GitHub Actions, AWS Lambda
